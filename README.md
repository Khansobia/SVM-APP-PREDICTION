# 📊 SVM Model Prediction App

This is a simple **Machine Learning project** created by **Sobia Khan** using **Support Vector Machine (SVM)**.  
It predicts the output class based on two input values — **X1** and **X2** — using a trained model saved as a `.pkl` file.

---

## 🧠 Project Overview

- **Algorithm Used:** SVM (Support Vector Machine)  
- **Dataset Used:** `mysvmkernel.csv`  
- **Language:** Python  
- **Libraries:** scikit-learn, streamlit, pickle, pandas  
- **Interface:** Streamlit Web App
